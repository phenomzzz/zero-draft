# Bilingual copy acceptance probes

Use with [copy-deslop.md](copy-deslop.md). These are test briefs and acceptance criteria, not completed evaluations. Do not feed expected outcomes to an independent evaluator when testing behavior. No external service, publication or paid evaluation is authorized by this file.

| Realistic request/input | Acceptance criteria | Failure to catch |
| --- | --- | --- |
| Refine an approved winery hero: "Aqui o dia começa mais devagar." | Retain or justify a contextual refinement; distinguish brand expression from practical copy | Deletes all poetic copy as slop |
| Simplify: "Cadeirinha infantil mediante consulta prévia e cobrança adicional." | Preserve both prior consultation and extra charge | "Child seats available" loses conditions |
| Improve "Consultar disponibilidade" opening a staff inquiry | Wording predicts inquiry; no confirmation or live inventory claim | "Reserve agora" implies capability not present |
| Edit English: "We may accept late returns if arranged in advance." | Preserve uncertainty and advance arrangement | "Return whenever you like" |
| Clean up a guild roster using Cutting Edge, Mythic and class names | Preserve correct domain terminology and verified achievement/status | Blanket banned-word replacement |
| Refine three actual features in a short card | Keep information and scanability; no forced prose expansion | Avoids triads at expense of UI clarity |
| Improve a vague shop description with no supporting facts | Conservative rewrite plus targeted gap if needed | Invents guided tours, awards or distances |
| PT-BR calendar validation says return must follow pick-up | Clear correction, unchanged date constraint, rendered readable label | Warmer copy removes recovery instruction |
| Mixed PT-BR recruitment copy contains raid, roster and progress | Retain audience-appropriate terms; consistent locale | Literal or PT-PT translation without authorization |
| Legal quotation contains a phrase on the diagnostic list | Leave quote intact and separate any editorial note | Rewrites source quotation |
| Compare original and edit with changed cancellation deadline | Reject on factual meaning before stylistic preference | Rewards smoothness despite changed commitment |
| Source note says date unknown; AI draft supplies 14 October | Keep uncertainty, flag conflict and avoid invented date | Treats generated detail as verified |
| Every section heading is "Two words. Accent word." | Vary syntax from content; keep the formula only where it is the brand line | Swaps in another uniform formula (all questions) |
| PT-BR draft: "Eleve sua estadia com soluções completas." | Supported concrete detail or a flagged gap | Synonym swap ("Aprimore sua estadia…") |
| PT-BR block: "R$1250.00 · 10/16/2026 · 2:00 PM" | "R$ 1.250,00 · 16/10/2026 · 14h", same values | Changes a value or keeps US formats |
| Draft adds "Trusted by 2,000+ customers" with no source | Remove or flag as unsupported | Keeps or rounds the invented number |

For an actual trial record input, source facts, scope, skill snapshot, output, evaluator method, observed failures and checks. Grade semantic preservation and action comprehension before preference. Include valid original copy as negative controls. Cover EN and PT-BR, expressive and functional copy, domain language and short/long viewport constraints. Randomize A/B order for reader preference tests. Distinguish source inspection, manual walkthrough, model judgment, rendered testing and native-reader findings. Do not report this fixture list or package validation as proof of editorial improvement.
