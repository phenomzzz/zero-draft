## Reference motion study

Five homepages are a small, award-biased sample: the mechanisms show current production craft, not proven usability or conversion.

## Adversarial audit revision

The experimental mode, generation/review ordering, house-default naming, divergence matrix, style tiles, dilution check and desktop-scoped rejections come from a single-reviewer desktop audit on 16 October 2026 of four builds of one brief and a local animation-demo library. The record is not published. Methods adapted: morphological charts (combining options across design axes), Samantha Warren's style tiles (visual language before layout), and findings that LLM ideation fixates on early outputs and converges across samples (Deng, Brucks & Toubia 2026). No external text or code is reproduced. These are hypotheses to test with [evals/](../evals/README.md), not validated improvements.

## What this package does not include

No cloned client site, production starter, hosting/CMS account, publisher or full accessibility/performance suite. No client photography, account identifiers, secrets or scraped proprietary designs. Tools aid inspection; they do not prove design quality.

The [motion kit](../assets/motion/README.md) holds nine components adapted and tuned in two of the author's production websites. Each started as a from-scratch recreation of a component in the annnimate catalog (annnimate.com), written only from the catalog's public component names, categories and attribute names. No annnimate code was viewed or copied, and none of its markup, styles or media were used. The kit README names the base component for each file. annnimate is not affiliated with this package.
