## Operation

Keyboard/touch; focus entry/containment/restore; Escape; background behavior; scrolling; loading/failure; reduced motion; animation interruption; cancel versus apply.

## Meaningful sequences

Initial/partial/complete; edit either endpoint/value; clear; apply/cancel/reopen; stale persisted data; rapid reversal; narrow and short screen; multiple entry points. Add only sequences relevant to this component.
